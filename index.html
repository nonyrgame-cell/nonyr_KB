Дисциплинарный устав

Особого Конструкторского Бюро «nonyr»
Документ № ОКБ-nonyr-001

Раздел I. Общие положения

1.1. Канал nonyr — ядро инженерной империи. Сообщество людей, занимающихся инженерией, которые собираются вместе ради общего могущества.

1.2. Цель — построение инженерной империи. Процесс не заканчивается. 1000 подписчиков — первый рубеж, не цель.

1.3. Дисциплина — основа производства. Без дисциплины нет ни расчёта, ни пуска, ни империи.

1.4. Настоящий устав обязателен для всех участников чата и стрима.

Раздел II. Производственная дисциплина

  • Компетентность. Не знаешь — спроси. Не уверен — пересчитай. Ошибся — признай и исправь.
  • Конструктивность. Критикуешь — предлагай альтернативу с обоснованием. «Всё плохо» без решения — нарушение.
  • Чёткость. Формулируй мысль. Оформляй расчёт. Указывай данные, на которые опираешься.
  • Ответственность. Сказал — сделай. Взял задачу — доведи до конца. Не можешь — предупреди заранее.

Раздел III. Запрещено

Код Нарушение Санкция
З-01 Оскорбления, переход на личности Мут/Бан
З-02 Спам, флуд, провокации Мут
З-03 Публикация заведомо ложных данных Предупреждение
З-04 Саботаж (срыв стрима/испытания) Бан
З-05 Реклама без согласования Предупреждение
З-06 Политика/религия вне производства Предупреждение

Раздел IV. Санкции

  • Нарушение №1 → Предупреждение (фиксация в журнале)
  • Нарушение №2 → Мут (временное отстранение, 24ч)
  • Нарушение №3 → Бан (бессрочное отстранение)
  • Особо злостный саботаж → Бан без предупреждения

Решение о санкциях принимает модератор. Окончательное — Главный Конструктор.

Раздел V. Обязанности участников

  • Соблюдать настоящий устав
  • Уважать чужой труд: крафты, расчёты, мнения
  • Помогать новичкам: объяснять, подсказывать, направлять
  • Фиксировать результаты: удачи и аварии — в журнал
  • Участвовать в разборах: анализ — часть производства

Раздел VI. Права участников

  • Задавать вопросы
  • Предлагать решения
  • Спорить с аргументами
  • Показывать свои крафты
  • Ошибаться
  • Расслабиться и общаться — вне производственной необходимости

Раздел VII. Роль Главного Конструктора

  • Принимает окончательное решение по пуску
  • Несёт ответственность за результат
  • Выслушивает чат. Решает — сам
  • Решение не обсуждается в момент пуска. Обсуждается после — в разборе
  • Главный Конструктор подчиняется уставу. Не наоборот

Раздел VIII. Модерация

  • Модератор — служба безопасности предприятия
  • Модератор следит за соблюдением устава
  • Модератор имеет право на предупреждение, мут, бан
  • Модератор подчиняется Главному Конструктору
  • Действия модератора можно обжаловать у Главного Конструктора

Раздел IX. Разборы и журнал

  • После каждой смены — короткий разбор: что делали, что вышло, что нет, почему
  • Результаты — в журнал: дата, задача, результат, вывод
  • Журнал — общий. Доступен всем участникам
  • Авария — не повод для паники. Повод для записи в журнал

Раздел X. Изменения устава

  • Устав может быть изменён Главным Конструктором
  • Предложения по изменению принимаются от участников
  • Изменения вступают в силу с момента публикации
  • Устав не противоречит ТЗ. ТЗ первично

Приложение. Формулировки для закрепа

  1. Инженерия — это дисциплина, а не талант
  2. Ошибка — это данные. Записываем, разбираем, строим заново
  3. Знание, которым поделились, — живёт
  4. Мы собираемся ради нашего же могущества
  5. Критикуешь — предлагай. Не можешь предложить — слушай
  6. Дисциплина — основа производства
  7. Империя не имеет финальной метрики
